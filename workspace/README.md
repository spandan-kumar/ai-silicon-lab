# Agent workspace

This is the only area the future design agent is expected to modify during
normal experiments. Choose any architecture, ISA, language, simulator, or
hardware/software split that the objective justifies.

The subdirectories are initial conceptual areas, not a required workflow:

- `rtl/` — HDL and RTL-support code;
- `firmware/` — boot code and low-level software;
- `software/` — applications, runtimes, compilers, and libraries;
- `experiments/` — temporary or named experiment source;
- `tools/` — profilers, generators, adapters, and utilities;
- `docs/` — design notes and research records.

The lab does not assume that all of these will be used.
