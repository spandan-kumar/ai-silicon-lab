# Licensing notes

The reference game data is Freedoom Phase 1 from the official `freedoom`
project, source tag `v0.13.0`. Its license and credits are included in
`ground_truth/assets/FREEDOOM-LICENSE.txt` and `ground_truth/assets/CREDITS`.
The IWAD is free content intended for redistribution; it is not a copy of a
commercial DOOM IWAD.

The reference engine is the pinned `ozkl/doomgeneric` project. Its upstream
license is included at `ground_truth/reference/vendor/doomgeneric/LICENSE`.
The evaluator and small lab adapters are MIT-licensed by this repository's
author unless a file states otherwise.

Do not add a commercial `DOOM.WAD` or other copyrighted game data to Git. A
future experiment that elects to use a user-supplied commercial WAD must keep
it outside the repository and document that requirement explicitly.
